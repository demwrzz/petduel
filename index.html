🔒 How Provably Fair Works

Every coinflip match is 100% fair and verifiable. Before the match starts, the server generates a secret serverSeed and publishes its cryptographic SHA-256 hash (Match Hash) to the lobby.

When the match is joined, the winner side is calculated deterministically on the backend via HMAC-SHA256 using the match ID and secret seed. Once the match finishes, the raw `serverSeed` is revealed so anyone can independently check that the outcome was predetermined and unmanipulated.
